# QR-Code-Generator
A simple qr code generator

# How to install
1. Download the main.exe file from this github repo
2. Run it in you pc/laptop by double clicking the downloaded file

# How to access game code
1. DOwnload the main.py file form this repo
2. Then open it in any code editors like VS Code, IDLE, Pycharm, etc

# Libraries Used
1. Tkinter
2. PIL (Python Imaging Library)
3. qrcode
4. io
